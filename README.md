## 👨‍💻 About Me

- 🎨 I build **PWA** web apps, bilingual **Vietnamese/English**, following **Material Design 3** standards
- 🛠️ Core stack: Vanilla JS PWA, React + Vite, ASP.NET Core, Supabase, Google Apps Script
- 🌗 Every project ships with light/dark/system theme, localStorage, offline-first support
- 📦 Products are packaged and delivered as ready-to-deploy ZIP files
- 🧩 Passionate about clean UI, One UI–style squircle icons, no emoji in interfaces
- 🌱 Currently diving deeper into Supabase, real-time data, and OAuth flows
- 💬 Can communicate in Vietnamese or English
